# Separate testimony, one human-reviewed packet

1. Participant A submits a report from their own account.
2. On that case, A consents to sharing a confirmed account/observations and creates a private, single-use invitation code. The code expires after 24 hours.
3. Participant B creates a **separate report** from their own account, enters the code and gives sharing consent. Their original statement is not overwritten or merged with A's statement.
4. A reviewer sees the requested relationship, reads the accounts/evidence, and accepts or rejects the link. A shared code is not proof the accounts concern the same incident.
5. Only after reviewer approval and both sharing consents can the participants see each other's confirmed account and damage observations. Private photos and support requests are not shared with the other participant.
6. The reviewer opens the joint report, preserves original testimony and confirmed drafts separately, records unresolved disagreements and approves that exact packet.
7. The reviewer can simulate department intake and insurance intake. Each local demo receiver produces a `SIM-…` receipt. Both source cases show the routing history.

No person is automatically labeled “the cause,” “guilty,” or an officially determined victim. A self-described affected participant is a claim, not a liability verdict. Cause, injuries, roadworthiness and legal outcomes remain undetermined.

New evidence, corrections, participant information or linked accounts invalidate an older packet approval. The reviewer must inspect the current packet again. Repeating the same simulated dispatch reuses its receipt rather than creating duplicates.

## Real department / insurance integration

The PDF explicitly places live integrations after authorized agreements. This implementation does not contact real recipients, send email or issue official reports. A production connector needs an authorized endpoint, authentication, a documented payload/consent contract and a permitted recipient before real information can be transmitted.
